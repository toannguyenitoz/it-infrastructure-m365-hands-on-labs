# Integrated Scenario — New Employee Onboarding

## Scenario
A new employee requires a domain identity, Windows device, Microsoft 365 services, Outlook, assigned asset and a complete support handover.

## Workflow

1. Receive an approved onboarding request containing manager, department, start date and access list.
2. Create the Active Directory user in the correct OU.
3. Assign access through approved role-based groups.
4. Join or verify the assigned Windows device in the domain.
5. Create or synchronise the Microsoft 365 identity.
6. Set usage location and assign the approved licence.
7. Require secure first sign-in and MFA registration.
8. Configure Outlook and test mail and calendar.
9. Create or assign the asset in ServiceDesk Plus and link it to the user.
10. Verify monitoring access when the employee supports infrastructure.
11. Document evidence, exceptions, ownership and handover.
12. Close only after user or manager confirmation.

## Evidence matrix

| Skill | Evidence |
|---|---|
| Identity and access | Correct OU, groups, least privilege and MFA |
| Networking | DNS, time, ports, domain trust and connectivity |
| Cloud administration | Licence and service-plan verification |
| Endpoint support | Outlook authentication, profile and synchronisation |
| ITSM | SLA, communication, ownership and closure |
| Security | No credential exposure and complete audit trail |

## Completion standard
The scenario is complete only when the employee can securely sign in, access approved resources, use email/calendar, identify their assigned device and obtain support through the documented service channel.
