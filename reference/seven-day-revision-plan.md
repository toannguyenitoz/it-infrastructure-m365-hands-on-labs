# Seven-Day Fast Revision Plan

| Day | Focus | Deliverable |
|---:|---|---|
| 1 | AD users, password reset, groups and OUs | Create three users and explain reset versus change |
| 2 | DNS and domain join | Join one client, break DNS and repair it |
| 3 | Microsoft 365 user, licence and MFA | Create a lab user and verify service plans |
| 4 | Outlook and Service Desk | Configure mail and process one ticket end to end |
| 5 | `systemctl` and `journalctl` | Install a service, cause one failure and solve it with logs |
| 6 | Zabbix and Grafana | Collect one host metric and build four panels |
| 7 | Incident/change documentation and interview | Write one incident, one change and answer all interview questions |

## Final self-test

- Can I explain every lab in 60 seconds?
- Can I perform it without following screenshots?
- Can I prove success with commands or sanitised evidence?
- Can I name three common failures and isolate them?
- Can I explain security and least-privilege considerations?
- Can another technician follow my documentation?

## Pass standard

You are job-ready for a skill only when you can **perform, verify, troubleshoot and explain it** — not when you have only read the procedure.
