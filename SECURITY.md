# Security Policy

## Safe-use scope

This repository is for authorised education, lab practice and portfolio development. Do not run examples against systems, tenants or networks you do not own or administer with permission.

## Never publish

- Passwords, temporary passwords or password hashes
- API keys, access tokens, certificates or PSK material
- Real tenant names, customer identities or personal information
- Internal hostnames, public IP addresses or production topology
- Unredacted logs, email content or ticket attachments

## Lab controls

Use isolated virtual machines, snapshots, non-production tenants, host-only or restricted networking, least-privilege accounts and firewall allow-lists. Replace all default credentials immediately.

## Reporting a security concern

Do not open a public issue containing exploitable secrets or personal data. Contact the repository owner through the links below with a sanitised description.
